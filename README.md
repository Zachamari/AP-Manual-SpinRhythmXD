# AP-Manual-SpinRhythmXD
An Archipelago Manual for Spin Rhythm XD.

This was created using [KillerAwesomexX's Manual Rhythm Game Randomizer](https://github.com/KillerAwesomexX/KayaysManualRandomizers/releases/tag/MRGR-Prerelease-v2.3.0), and I take no credit for any of the actual backbone of this manual.
Really the only reason I made this a repository is so I can more easily submit this manual to public games.

# Notes
This manual currently doesn't have any options, thus it assumes that you have the Monstercat and Indie DLCs, as those are the two DLC packs I own. If you want to play this manual yourself and you don't have those DLCs (or if you want to add the Chillwave DLC or the Supporter Pack-exclusive track), I included the song.txt file that you can edit to use with MRGR for your own version of the manual. 

I likely won't add options to this or anything since I'm expecting that I'll probably be the only person using it, but if you stumble across this and want me to add options, feel free to reach out! I can do it easily, I'm just lazy.
